Why both must be hosted (not run locally)

Argus app — business users need a stable URL they can bookmark and share. Running on a laptop means the app disappears when the machine sleeps or leaves the office. Azure App Service gives it a persistent HTTPS endpoint with M365 Easy Auth so Aurora staff sign in with their existing Microsoft credentials, no separate accounts needed.

MCP server — Claude Enterprise connects to MCP servers over HTTP at a fixed URL configured in the Claude admin console. There is no way to point Claude at a local machine or ngrok tunnel in a production org. The server must be live at a stable HTTPS address at all times — Claude calls it on demand whenever a user triggers one of the 9 tools, so downtime means broken AI queries. M365 Easy Auth in front also ensures only Aurora-authenticated users can trigger data access, which is required for governance.
